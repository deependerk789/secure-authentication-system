## 🚀 About the Project

Secure Authentication System is a Flask-based web application that demonstrates secure authentication and essential cybersecurity practices. It focuses on password protection, session security, CSRF defense, two-factor authentication and authentication audit logging.

## ✨ Key Features

| Feature | Description |
|---|---|
| 🔑 Authentication | User sign-in and authentication flows |
| 🔒 Password Security | Argon2id password hashing |
| 🛡️ CSRF Protection | Helps protect forms from cross-site request forgery |
| ⏱️ Session Security | Signed, time-limited sessions |
| 🔐 Two-Factor Authentication | TOTP-based verification |
| 📝 Audit Logging | Records authentication activity |
| 📊 Security Dashboard | Shows security configuration status |
| 🧪 Automated Testing | Tests authentication functionality |

## 🛠️ Technology Stack

<p align="center">
  <img src="https://skillicons.dev/icons?i=python,flask,sqlite,html,css,git,github" alt="Technology stack icons"/>
</p>

- **Language:** Python
- **Framework:** Flask
- **Database:** SQLite
- **Password hashing:** Argon2id
- **Two-factor authentication:** TOTP
- **Testing:** Pytest

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/deependerk789/secure-authentication-system.git
cd secure-authentication-system
```

### 2. Create a virtual environment

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

Use `.env.example` as a reference and configure the variables required by your application.

**Never commit your `.env` file, passwords, or production secrets.**

### 5. Start the application

Use the actual entry point configured in your project. For example, if it is `app.py`:

```bash
python app.py
```

Open the local address displayed in the terminal.

### 6. Run tests

```bash
python -m pytest -q
```
